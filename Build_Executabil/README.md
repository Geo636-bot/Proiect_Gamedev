# Windows build

| File | Sprint | Unity |
|---|---|---|
| `ProiectGamedev_Sprint1_Windows.zip` | Sprint 1 | 6000.6.8f1 |

How to run it:

1. Unzip the file into a folder.
2. Run `ProiectGamedev.exe` (Windows 10/11, 64-bit).
3. If you see "Windows protected your PC" (SmartScreen): **More info** → **Run anyway**. The build is not digitally signed, which is why the warning shows up.

The controls are in the [main README](../README.md#controls).
